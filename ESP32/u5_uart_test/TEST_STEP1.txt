Step 1: U5 ↔ ESP32 UART 联调
==========================

接线
----
  U5 CN12 pin25 PB10 (TX)  ----->  ESP32 GPIO20 (RX)
  U5 CN12 pin18 PB11 (RX)  <-----  ESP32 GPIO21 (TX)
  GND                      -------  GND

记忆：TX 接 RX，交叉；必须共地。

ESP32（队友或你先烧这一版）
--------------------------
  文件夹: D:\嵌赛\ESP32\u5_uart_test\
  文件:   u5_uart_test.ino
  板型:   ESP32C3 Dev Module
  无需 WiFi，无需 Maix

  USB 串口监视器 115200 应看到:
    [UART] sent READY, waiting for PING...
    [U5->] PING
    [U5<-] PONG

U5（你）
--------
  Keil Rebuild + 烧录（APP_MAIXCAM_ENABLE=1 已开）
  上电顺序: 先 ESP32，再复位 U5（U5 有 5s 延迟才发 PING）

  ST-Link 串口 115200 应看到:
    [ESP32] USART3 PB10/PB11 @ 115200
    [ESP32] step1 UART: wait READY/PONG from ESP32
    [ESP32] pre-ping rx=5B        (收到 READY)
    [ESP32] TX PING (OK)
    [ESP32] PONG
    [ESP32] UART OK (PONG)

故障
----
  NO RX: 线接反 / 没 GND / ESP 未烧 u5_uart_test.ino
  got bytes but no PONG: ESP 跑错程序（用了 WiFi 版且没连 Maix）

通过后
------
  再换 D:\嵌赛\ESP32\u5_maix_bridge\u5_maix_bridge.ino 做 Step 2（加 WiFi→Maix）
